# 运行态真源（舱隙 / podrift）

## 选定真源

二选一必须选一臂，落库在 `settings.运行态真源`，读侧每次取数按它重放：

- **臂A `列`**（默认，种子即此臂）：`pods.run_state` 是唯一真源。启停单灯与事件痕只是附件，
  不得用灯/流水改写已刷运行态。手改运行态列 = 权威改写。
- **臂B `灯`**：启停单「已完成」灯是唯一真源，`pods.run_state` 只是缓存。读侧按单据倒序重放，
  手改列必须声明「纠偏」当场翻灯，否则 409；下一笔启停推进同笔把缓存刷平，不留长期双账。

切换：`POST /api/舱规 {"key":"运行态真源","value":"列|灯"}`（「舱规」「对读屏」两页均有按钮），
切臂与事件痕同笔落库。环境变量 `PODRIFT_TRUTH=列|灯` 可覆盖（测试用）。

## 事务口径

`app/db.py` 的 `db(write=True)` 以 `BEGIN IMMEDIATE` 开写锁，提交失败整笔回滚。
运行态列改写（`apply_run_state`）与启停单/事件落库在同一事务内：

| 动作 | 结果 |
| --- | --- |
| 启动，镜像未就绪 / 配额不足 | `失败`，运行态与配额不动 |
| 停止，当前真源非运行中 | `未生效`，不再谎点「已完成」 |
| 启动，已在运行中 | `未生效` |
| 真正翻转 | `已完成`，记录 `prev_state → result_state`、`state_rev` |

配额占用由 `pods.quota_held` 精确对账，手改运行态同样回补/归还，不重复计价。

## 读侧投影（互证）

`GET /api/舱体`、`GET /api/对读`、`GET /api/启停单` 同时给出：

- `运行`：依选定真源重放后的运行格（唯一权威格）
- `列` / `列版本`：原始列值与版本号（并发与手改审计）
- `灯` / `灯态`：附件灯，只有真的翻转才亮「已完成」
- `漂移` / `漂移类型`：两臂下分别标「灯附件过期」「缓存偏差」，并附说明
- 事件痕（`GET /api/事件`）：每条都带 `前→后 [状态] rev=… 真源=…`

## 验收入口

```bash
pip install -r backend/requirements.txt pytest httpx
python -m pytest backend/tests -q      # 18 条夹具
```

夹具覆盖：手改运行态列再推进启停、推进后再改列、并发双写（启动×2 / 启动×停止）、
半截脏服役回滚（含配额已加后抛错）、「列停灯成」两臂裁决分开验、四处互证同口径。

手工核验：把臂切到 `列`，`/pods` 手改 web-a 为运行中 → `/align` 运行格跟列；随后在 `/orders`
推停止单，灯变「已完成·已停止」，`/rules` 事件痕一行对齐。再把臂切到 `灯`，用旁路把列改脏
（或直接改列触发 409），`/align` 运行格跟灯并标「缓存偏差」，勾「纠偏」后当场刷平。
